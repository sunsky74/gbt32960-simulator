# 插件包编写指南

> 适用版本:GB/T 32960 客户端模拟器(P4 扩展包机制)
> 读者:协议对接实施人员。不需要写代码,也不需要懂 Go —— 只需要会写 JSON。

---

## 1. 概览

扩展包(俗称"插件包")是一个 JSON 文件,用来给模拟器增加**私有数据**能力:

- **实时报文追加单元**:在标准 0x02 实时报文末尾,追加私有 TLV 数据单元(比如厂商自己的遥测数据)。
- **私有命令字**:定义标准之外的私有上行命令(比如"扩展数据上报""扩展报表"),支持手动或周期发送。

一个扩展包 = 元信息 + 实时追加单元 + 私有命令。写好 JSON 后在应用设置页导入,再在连接档案里绑定,即可使用。

| 能力 | 说明 |
|---|---|
| 实时追加单元 | 拼在标准 0x02 报文尾部,随实时上报/补发/周期上报一起走 |
| 私有命令字 | 独立的私有命令帧,手动或周期发送 |
| 字段 DSL | 用声明式字段表描述报文布局,自动生成填表表单 |
| 码位安全 | 导入时强校验,防止占用标准码位或与标准组冲突 |

示例包随仓库提供:`docs/extpack/sample-pack.json`,可直接复制改造成自己的包。

---

## 2. 快速开始

以仓库内置示例包为例,从零到第一条私有报文,步骤如下:

1. **准备包文件**:复制 `docs/extpack/sample-pack.json` 到任意目录(比如桌面),保持文件名不变即可。
2. **导入**:打开应用 → 左侧导航进入**设置**页 → "扩展包管理"区 → 点击**导入**按钮,在弹出的文件选择对话框中选择 `sample-pack.json`。导入成功后,列表中出现"示例·私有遥测包"。
3. **绑定连接档案**:进入**客户端模拟**页 → 在连接配置卡片中找到**扩展包**下拉框 → 选择 `sample-private` → 保存连接档案(若提示切换版本等,按提示处理)。
4. **连接**:按正常流程连接服务器。
5. **填写扩展数据**:
   - **实时数据**页:标准组之后出现"私有遥测单元"组(示例包中默认未启用,勾选启用即可;配置 SOC2、包电压两个值)。
   - **自定义数据**页:出现"扩展数据上报"与"扩展报表"两个命令表单。填好流水号、电压等字段。
6. **发送**:
   - 实时追加单元:随实时上报发送;周期上报开启时也会携带。
   - 扩展命令:点击**发送**按钮手动发送;"扩展数据上报"的触发方式是"手动+周期",也可以在命令区打开周期开关。
7. **验证**:在**控制台**查看 TX(发送方向)hex 报文。示例包会在标准 0x02 报文尾部看到 `80` 开头的私有 TLV(单元码 0x80 = 128),扩展命令则看到命令码为 `09`、`0A` 的帧。

看到 TX 里出现 `80 xx xx …` 或 `09/0A` 开头的私有数据,说明扩展包已经生效。

## 3. 包格式

一个扩展包是一个 JSON 对象,顶层三个键:`meta`、`realtime`、`commands`。完整示例见 `docs/extpack/sample-pack.json`。

### 3.1 meta(必填)

| 键 | 说明 | 规则 |
|---|---|---|
| `id` | 包唯一标识 | 2~64 位小写字母、数字、连字符 `-`;以字母或数字开头;同 id 导入会覆盖旧包 |
| `label` | 显示名 | 非空;在包列表、绑定下拉框中显示 |
| `vendor` | 厂商名 | 可选,仅展示用 |
| `baseVersion` | 协议版本 | 只能填 `"2016"` 或 `"2025"`,与连接档案的协议版本必须一致 |
| `scope` | 应用范围 | 可选,数组,取值 `"client"`(客户端模拟)/ `"parser"`(报文解析);缺省视为 `["client"]` |

```json
"meta": { "id": "sample-private", "label": "示例·私有遥测包", "vendor": "示例", "baseVersion": "2016", "scope": ["client", "parser"] }
```

**应用范围(scope)说明**:

- `client`:包参与客户端模拟——实时追加单元、私有命令、私有远控 0x8A 应答模板(即原有全部行为)。
- `parser`:包出现在**报文解析页**的"扩展包"下拉框中;选中后解析报文时,自定义数据单元(unitCode 0x80~0xFE)按包内字段 DSL 逐字段解码(字段名、类型、物理值 = 线值×scale+offset),与发送侧编码互逆。
- 声明 `["parser"]`(不含 client)的包**只**用于解析页:不参与客户端模拟,连接档案也不会合并它的扩展组。
- 解析时包的 `baseVersion` 与报文实际版本不一致,自定义单元退化为通用展示并给出告警。

### 3.2 realtime.appendUnits(实时追加单元,可多个)

每个单元是拼接到标准 0x02 报文尾部的一个 TLV。字段如下:

| 键 | 说明 | 规则 |
|---|---|---|
| `key` | 组键 | 非空;禁含冒号 `:`;禁与标准组键同名(见 §5);同包内唯一 |
| `title` | 组标题 | 显示在实时数据表单里 |
| `unitCode` | 单元码(信息标识) | 整数,只允许 **0x80~0xFE**(128~254),同包内唯一 |
| `enabled` | 默认是否启用 | `true` / `false`;`false` 时表单默认不勾选,不参与编码 |
| `multiple` | 是否多行 | `true` 时表单提供加行/删行,**每行编码为一个独立 TLV**;`false` 单行 |
| `maxRows` | 最大行数 | `multiple: true` 时有意义;不得为负数 |
| `fields` | 字段表 | 至少一个字段,见 §4 |

```json
"appendUnits": [
  {
    "key": "customTelemetry", "title": "私有遥测单元",
    "unitCode": 128, "enabled": false, "multiple": false, "maxRows": 10,
    "fields": [
      { "key": "soc2", "label": "SOC2", "type": "u8", "unit": "%" },
      { "key": "packVolt", "label": "包电压", "type": "u16", "scale": 0.1, "unit": "V" }
    ]
  }
]
```

### 3.3 commands(私有命令字,可多个)

| 键 | 说明 | 规则 |
|---|---|---|
| `key` | 命令键 | 非空;禁含冒号 `:`;禁与标准组键同名;同包内唯一 |
| `label` | 命令显示名 | 非空 |
| `code` | 命令码 | 整数,只能落在上行预留区(2016: 0x09~0x7F;2025: 0x0C~0x7F),同包内唯一 |
| `direction` | 方向 | 本期只支持 `"up"`(上行) |
| `trigger` | 触发方式 | `"manual"`(仅手动)/ `"periodic"`(仅周期)/ `"manual+periodic"`(手动+周期) |
| `body` | 命令体 | 见下 |

`body.type` 三种:

- **`fields`**:平铺字段表,表单为**单行**。`body.fields` 至少一个字段。
- **`realtimeLike`**:与实时报文同构(命令体 = 6 字节时间 + 若干 TLV)。`body.units` 至少一个单元,单元结构与 §3.2 完全一致;`multiple: true` 时**多行,每行一个 TLV**。
- **`remoteAck`(0x8A 远程控制应答模板)**:命令 `code` 固定 `138`(0x8A)、`direction: "up"`,额外声明 `remoteSub`(子指令码 0x01~0x11,私有远控 私有远控协议)。发送时走**应答标志 0x01**,载荷 = 表21头(命令时间 6B + 流水号 2B + 命令总数 1 + 子指令码 1B)+ 应答体平铺字段。**约定**:`body.fields` 首字段必须为 `{"key": "serialNumber", "type": "u16"}`(编码时提取填入表21头流水号,用于回显下行请求);应答体尾部可用一个 `type: "tail"` 字段承载变长的故障列表(hex: 故障总数 N 1B + N×4B,无故障填 `00`)。仅 2016 版支持。

```json
{
  "key": "ackRemoteLock", "label": "0x8A/0x09 锁车限速 应答", "code": 138,
  "direction": "up", "trigger": "manual", "remoteSub": 9,
  "body": { "type": "fields", "fields": [
    { "key": "serialNumber", "label": "命令流水号(回显下行)", "type": "u16" },
    { "key": "lockStatus", "label": "锁车状态", "type": "bits", "bits": [
      { "index": 0, "label": "锁车状态(bit0)" }, { "index": 1, "label": "锁车状态(bit1)" },
      { "index": 2, "label": "限速状态" }
    ] },
    { "key": "faultList", "label": "故障列表(hex: 总数N + N×4B,无故障 00)", "type": "tail" }
  ] }
}
```

完整示例见 `docs/extpack/local-pack-v16.json`(私有远控 2016 实时扩展 11 单元 + 0x8A 远控 16 个子指令应答模板)。

```json
"commands": [
  {
    "key": "extData09", "label": "扩展数据上报", "code": 9, "direction": "up", "trigger": "manual+periodic",
    "body": { "type": "fields", "fields": [
      { "key": "seq", "label": "流水号", "type": "u16" },
      { "key": "volt", "label": "电压", "type": "u16", "scale": 0.1, "unit": "V" }
    ] }
  },
  {
    "key": "extReport0A", "label": "扩展报表", "code": 10, "direction": "up", "trigger": "manual",
    "body": { "type": "realtimeLike", "units": [{
      "key": "telemetry", "title": "私有遥测", "unitCode": 129, "enabled": true, "multiple": true, "maxRows": 5,
      "fields": [
        { "key": "soc", "label": "SOC", "type": "u8", "unit": "%" },
        { "key": "temp", "label": "温度", "type": "i8", "offset": 40, "unit": "°C" }
      ]
    }] }
  }
]
```

## 4. 字段 DSL 类型表

字段表 `fields` 里每个字段是一个对象:`key`(键,组内唯一、非空)、`label`(显示名,非空)、`type`(类型)、`unit`(单位,仅展示)。按 `type` 分九类:

| 类型 | 含义 | 线长(字节) | 取值范围(线值) |
|---|---|---|---|
| `u8` | 无符号 8 位整数 | 1 | 0 ~ 255 |
| `u16` | 无符号 16 位整数 | 2 | 0 ~ 65535 |
| `u32` | 无符号 32 位整数 | 4 | 0 ~ 4294967295 |
| `i8` | 有符号 8 位整数 | 1 | -128 ~ 127 |
| `i16` | 有符号 16 位整数 | 2 | -32768 ~ 32767 |
| `i32` | 有符号 32 位整数 | 4 | -2147483648 ~ 2147483647 |
| `f32` | 32 位浮点(IEEE 754) | 4 | — |
| `bits` | 位段(开关位) | 1/2/4(按最大位号自动) | 每位一个开关 |
| `bytes` | 原样字节 | 1~255(由 `length` 指定) | hex 字符串输入 |
| `tail` | 变长尾部 | 任意(含 0) | hex 字符串输入,原样追加;用于按数量变化的尾部(如故障列表);不支持 scale/offset/length/bits,建议放字段表末尾 |

### 数值变换契约(scale / offset)

**物理值 = 线值 × scale + offset**。表单里填写的是物理值(比如 12.3 V),编码时反算出线值写入报文。

| 规则 | 说明 |
|---|---|
| `scale` 缺省 1,`offset` 缺省 0 | 不填即 1:1 直通 |
| `scale ≤ 0` 非法 | 导入直接报错 |
| 反算结果必须为整数 | 例如 `scale: 0.1` 时填 12.35 V → 线值 123.5,编码报错拒绝发送,不静默截断 |
| `offset` 必须为整数 | 半整数偏移请改写为 scale 表达(如 `offset: 0.5` 改为 `scale: 0.5`,值域等价) |
| `f32`、`bits`、`bytes` 不支持 scale/offset | 声明了会报错 |

常用组合示例:

- 0.1 精度的电压:`"type": "u16", "scale": 0.1` → 线值 1234 = 123.4 V
- 偏移 40 的温度(国标惯例,-40~87℃ 映射 0~127):`"type": "i8", "offset": 40` → 物理 -40 = 线值 0

### bits 与 bytes

- `bits`:子项 `bits` 数组,每项 `{ "index": 0~31, "label": "名称" }`,index 同字段内不重复;表单渲染为开关组。
- `bytes`:`length` 定长 1~255,表单里填 hex 字符串(如 `1A2B`),长度不符或非 hex 会报错。

## 5. 码位规则

导入校验的完整规则(与设计契约 §4.4 一致)。**不满足的包无法导入**,错误信息会给出具体位置。

### 单元码 unitCode

| 项目 | 2016 | 2025 |
|---|---|---|
| 标准占用(拒绝) | 0x01~0x09 | 0x01~0x08、0x30(燃料电池电堆)、0x31(超级电容)、0x32(超容极值)、0xFF(签名) |
| 私有可用(**自定义数据区**) | **0x80~0xFE** | **0x80~0xFE** |

只允许 0x80~0xFE:这一区间与协议库的自定义 TLV 编解码区完全重合,扩展数据天然可以被报文解析页/服务端模式解码;0x0A~0x7F 是标准预留区,0xFF(2016)不可解码,一律拒绝。

### 命令码 code

| 项目 | 2016 | 2025 |
|---|---|---|
| 标准占用(拒绝) | 0x01~0x08 | 0x01~0x0B |
| 本期可用(上行预留区) | **0x09~0x7F** | **0x0C~0x7F** |
| 其余区(0x80~0x82 / 0x83~0xBF / 0xC0~0xFF) | 拒绝(下行扩展后续版本) | 同左 |

### 同包唯一性

- **unitCode**:包内所有单元(实时追加单元 + realtimeLike 命令体单元)共享一个命名空间,不得重复。
- **key**:命令键、单元键共用命名空间,包内不得重复(字段 key 仅在各自字段表内唯一)。
- **命令码 code**:包内不得重复。

### key 命名限制

- 禁含冒号 `:`(与内部命令组键的命名空间冲突)。
- 禁与标准报文组键同名,保留表:`vehicle`、`motor`、`fuelcell`、`engine`、`location`、`extremum`、`alarm`、`voltage`、`temperature`、`minparallel`、`batterytemp`、`fcstack`、`supercap`、`supercapextremum`。

### 其他

- `direction` 仅支持 `up`;`trigger` 只能是 `manual` / `periodic` / `manual+periodic`。
- `maxRows ≥ 0`;`fields` 与 `body.units` 都至少一项。

## 6. 错误信息解读

导入失败与保存失败时,错误信息都带**位置**,照着改即可。

### 导入校验错误(带 JSON 路径)

所有静态校验错误都带 JSON 路径,格式如 `realtime.appendUnits[0].fields[3].scale` —— 即 `realtime` 下第 1 个追加单元的第 4 个字段的 `scale` 属性。常见例子:

| 错误示例 | 含义 | 改法 |
|---|---|---|
| `meta.id: 须为 2~64 位小写字母/数字/连字符: "MyPack"` | id 含大写 | 改成 `mypack` |
| `realtime.appendUnits[0].unitCode: 0x09 为标准数据单元,禁止占用` | 占了标准码位 | 换成 0x80~0xFE |
| `realtime.appendUnits[0].fields[1].scale: 须大于 0` | scale 非法 | 填正数或删掉 |
| `commands[0].key: 键不能包含冒号(与命令组键命名空间冲突): "a:b"` | key 含冒号 | 去掉 `:` |
| `commands[0].key: 键与标准报文组冲突(保留键): "vehicle"` | key 撞保留表 | 换名 |
| `commands[0].code: 命令码重复: 0x0A 已被同包其他命令占用` | 命令码重复 | 换码 |

### 保存时的干跑错误

配置表单保存/发送前,会用填写的值做一次编码干跑,非法值在保存点拦截,不落盘。错误形如:

```
扩展命令 extData09: 字段 volt: 线值 66000 超出 u16 范围 [0, 65535]
```

- `扩展命令 X`:出错的是哪个扩展命令(`X` 为命令 key)。
- `字段 Y`:`Y` 为字段 key。
- `线值超范围`:填的物理值换算成线值后超出该类型的取值表(见 §4)。改小数值或换更大的类型。
- 非整数线值:如 `scale: 0.1` 时填 `12.35`,报"物理值 12.35 换算后不是整数线值",改填一位小数。

realtimeLike 多行时,错误会带单元与行号:`扩展命令 X 单元 Y 第 N 行: …`,定位到具体行。

## 7. 已知限制

以下为本版本(2026-09)的已知行为,属预期设计,请勿当作缺陷:

1. **重启后周期开关需重新开启**:扩展命令与标准实时上报的周期开关都是会话级状态,应用重启后不会自动恢复,需手动重新打开。
2. **解绑后配置随包保存、重绑恢复**:解绑一个包后,已保存的扩展组填表值仍随该包保存(按包独立存储);重新绑定同一包后配置自动恢复。
3. **覆盖导入同 id 会清除该包已保存的扩展组配置**:重新导入同 id 的包按"替换"处理,旧包已保存的行值会被清空(新旧布局的行值不兼容,不做迁移)。
4. **切换协议版本后扩展组配置重置为默认值**:前端切换协议版本时按默认值重新加载扩展组(设计口径,见评审 P1-3),填过的值不保留。
5. **标准组与扩展组分存两个文件**:极端崩溃下(如写入中途断电)两个文件可能各自停在最近一次成功版本,下次保存时会重新收敛,不影响使用。
6. **fields 体命令单行、realtimeLike 单元 multiple 时多行**:`fields` 体命令的表单永远是单行;`realtimeLike` 单元只有 `multiple: true` 才提供加行/删行(每行编码为一个独立 TLV),`multiple: false` 时也是单行。

## 8. 常见问题(FAQ)

**Q:点了导入没反应 / 列表里没出现?**
A:确认选择的是合法 JSON 扩展包文件。若文件非法,界面会给出带路径的错误(见 §6)。也可以先把仓库内 `sample-pack.json` 原样导入,确认流程本身正常,再对比自己的包。

**Q:"自定义数据" tab 是灰色的,点不了?**
A:当前连接档案没有绑定扩展包。进入连接配置卡片,在"扩展包"下拉框中绑定一个已导入的包并保存。

**Q:tab 点开提示版本不匹配?**
A:扩展包的 `meta.baseVersion` 与连接档案的协议版本不一致。二选一:把连接档案改成包声明的版本;或换一个版本匹配的包(改包 `baseVersion` 重新导入)。

**Q:实时数据里看不到我的追加单元?**
A:确认三件事:①已导入并绑定;②档案协议版本与包一致;③追加单元的 `enabled` 若为 `false`,需在表单里手动勾选启用。

**Q:发送后控制台 TX 里没看到私有数据?**
A:追加单元未勾选启用、或命令未点发送、或周期开关未开(见 §7 限制 1)。勾选/发送后再看 TX;私有 TLV 以 `80`~`FE` 单元码开头,扩展命令帧命令码为包声明的 `code`。

**Q:可以同时用多个扩展包吗?**
A:当前每个连接档案同时只绑定一个包;但可以导入多个包,按档案分别绑定。
